## 🌐 Маршруты (90 endpoints)

### Основные страницы
- `/` - Главная
- `/search` - Поиск поездок
- `/profile` - Профиль пользователя
- `/profile/<id>` - Публичный профиль
- `/create_ride` - Создать поездку
- `/ride/<id>` - Детали поездки
- `/chats` - Все чаты
- `/chat/<id>` - Чат поездки
- `/city-chat` - Городской чат
- `/news` - Новости
- `/notifications` - Уведомления

### API endpoints
- `/api/search_rides` - Поиск поездок
- `/api/book_ride` - Забронировать
- `/api/approve_booking` - Одобрить бронь
- `/api/rate_driver` - Оценка водителя
- `/api/rate_passengers` - Оценка пассажиров
- `/api/notifications` - Получить уведомления
- `/api/send_message` - Отправить сообщение
- `/api/favorite_routes` - Избранные маршруты
- `/api/regular_rides` - Регулярные поездки
- `/api/analytics` - Аналитика
- `/api/stats` - Статистика

### Аутентификация
- `/auth/login` - Вход
- `/auth/register` - Регистрация
- `/auth/logout` - Выход

## 🚀 Запуск проекта

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Запуск приложения
```bash
python app.py
```

### 3. Открыть в браузере
```
http://localhost:5000
```
