# 🚗 Север-Юг | Попутчики через бухту

Современная платформа для поиска попутчиков и организации совместных поездок.

## 🌟 Возможности

### Для водителей
- ✅ Создание и управление поездками
- ✅ Управление бронированиями (одобрение/отклонение)
- ✅ Оценка пассажиров
- ✅ Статистика и аналитика
- ✅ Регулярные поездки
- ✅ Чат с пассажирами

### Для пассажиров
- ✅ Поиск поездок с фильтрами
- ✅ Бронирование мест
- ✅ Оценка водителей
- ✅ Избранные маршруты
- ✅ История поездок
- ✅ Уведомления в реальном времени

### Общие функции
- ✅ Личный кабинет с настройками приватности
- ✅ Чат между пользователями
- ✅ Городской чат
- ✅ Система рейтингов
- ✅ Черный список
- ✅ Реферальная программа
- ✅ Поддержка (тикет-система)
- ✅ Новости и статьи
- ✅ Telegram интеграция

## 🛠️ Технологии

- **Backend**: Python 3, Flask
- **Database**: SQLite (SQLAlchemy ORM)
- **Frontend**: HTML5, CSS3, JavaScript (ES6+)
- **Security**: PBKDF2-SHA256, CSRF Protection, XSS Prevention
- **Design**: Modern UI with animations, gradients, responsive design

## 📦 Установка

### Требования
- Python 3.8+
- pip

### Шаг 1: Клонирование репозитория
```bash
cd /workspace
```

### Шаг 2: Установка зависимостей
```bash
pip install -r requirements.txt
```

### Шаг 3: Запуск приложения
```bash
python app.py
```

### Шаг 4: Открыть в браузере
```
http://localhost:5000
```

## 🔐 Безопасность

Проект включает современные меры безопасности:
- Хеширование паролей (PBKDF2-SHA256)
- CSRF защита всех форм
- XSS защита
- Валидация данных на клиенте и сервере
- Защита от brute-force атак
- Безопасные сессии
- Логирование действий пользователей
